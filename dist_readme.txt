양도소득세 홈택스+위택스 신고 자동화 — 사용 안내
====================================================

[준비물]
- Windows 10/11 (64비트)
- 본인 홈택스 / 위택스 로그인 수단(공동인증서 등) — 로그인은 직접 하셔야 합니다(자동화 안 됨)
- 양도박사 등으로 만든 변환파일
    · 홈택스 양도세 : *.01
    · 위택스 지방세 : *.Y13(예정) / *.Y11(확정)
- 부속서류 폴더 (안의 파일을 전부 첨부합니다)
- 'Microsoft Print to PDF' 프린터 (Windows 기본 제공) — PDF 저장 시 사용

[실행]
1. 압축을 풀고 YangdoAuto.exe 를 실행합니다. (설치 불필요)
   ※ 첫 실행 시 'Windows 보안 경고'가 뜨면 '추가 정보' → '실행'.
   ※ 첫 실행 때 브라우저 구성요소(약 150MB)를 자동 다운로드합니다(인터넷 필요, 1회).
      완료 전까지 [시작] 버튼이 비활성화되며, 진행 상황은 실행 로그에 표시됩니다.
      (같은 방식의 다른 프로그램을 이미 쓰고 있다면 이미 설치돼 있어 바로 시작됩니다.)
2. 실행할 단계를 켜고, 입력 정보(변환파일·주민번호·폴더 등)를 채웁니다.
3. [시작]을 누르면 홈택스·위택스 창이 열립니다. 두 사이트에 직접 로그인하세요.
   → 로그인이 확인되면 자동으로 진행됩니다.

[단계]
 ① 위택스 지방세 신고      ② 홈택스 양도세 신고      ③ 홈택스 부속서류 제출
 ④ 홈택스 접수증·신고서 출력  ⑤ 위택스 신고서 출력
 ⑥ 홈택스 납부서 출력      ⑦ 위택스 납부서 출력
 - 양도차손 등 납부서가 없는 건은 ⑥⑦을 꺼도 됩니다(켜도 '없음'으로 정상 종료).
 - 위택스 지방세 가상계좌는 신고 후 몇 분 뒤 생성되므로, ⑦ 시작 전 '위택스 납부서 대기'(분)만큼 기다립니다.

[옵션]
 - PDF 저장 / 출력(인쇄) 선택
 - 파일명에 성명 포함(공동명의 등)
 - 접수증·신고서 병합([접수증&신고서] 한 파일로)

[주의]
 - ①②③은 실제 '제출'까지 진행됩니다(비가역). 검증만 원하면 해당 단계를 끄고 쓰세요.
 - 로그인 정보는 저장하지 않습니다. 매 실행 시 직접 로그인합니다.
 - 데이터(로그인 세션)는 %LOCALAPPDATA%\YangdoAuto 에 저장됩니다.
